# Електро Трасе (POC)

Уеб приложение за чертане на трасета на ел. инсталация в апартамент.

- Чертане на стени (клик по ъглите, решетка 10 см, орто режим).
- Табло, контакти и ключове върху стени на зададена височина от пода.
- Разклонителни кутии на стена или на тавана, лампи на тавана.
- Кабели по стени (на височина) и по тавана, от табло/кутия до крайни точки.
- Метраж по тип кабел, проверки за несвързани елементи, изглед на стена.
- Мишка и клавиатура, таблет и телефон (докосване, 2 пръста за мащаб).

Стартиране: отворете `index.html` в браузър. Няма build стъпка.
