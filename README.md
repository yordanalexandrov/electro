# Електро 3D (POC)

Уеб приложение за проектиране на трасета на ел. инсталация в апартамент — в 3D.

**Демо:** https://yordanalexandrov.github.io/electro/

## Какво може

- **Стени** — чертаят се в изглед „План“ с клик/тап по ъглите (мрежа 10 см, орто режим, snap към съществуващи ъгли).
- **Табло, контакти, ключове** — поставят се върху стена на зададена височина от пода (в 3D — от страната, където кликнеш; в плана — на най-близката стена).
- **Разклонителни кутии** — на стена или на тавана; **лампи** — на тавана.
- **Кабели** — тръгват от табло/кутия/устройство, минават през произволни точки по стени и таван и завършват на устройство. Трасето се разгъва автоматично в ортогонални участъци по повърхностите (по една стена: вертикал → хоризонтал; между различни стени: нагоре → по тавана → надолу).
- Типове кабел с цветове, дължина по тип, предупреждения за несвързани устройства.
- Мишка + клавиатура (1–8 инструменти, Tab план/3D, Enter, Esc, Delete, Ctrl+Z, G) и докосване (тап = действие, влачене = въртене/местене, щипка = мащаб).
- Автоматично запазване в браузъра, експорт/импорт JSON.

## Стартиране

```sh
npm install
npm run dev      # http://localhost:5173/electro/
npm run build    # dist/
```

Деплой: GitHub Actions → GitHub Pages (`.github/workflows/pages.yml`).

## Структура

- `src/model.ts` — модел на данните (стени, устройства с „котва“ към стена/таван, кабели).
- `src/routing.ts` — разгъване на кабел в 3D точки по повърхности, дължини.
- `src/scene.ts` — Three.js сцена, камери (план/3D), raycast.
- `src/app.ts` — инструменти, взаимодействие, панел „Свойства“, обобщение, undo, запис.
- `legacy-2d/` — предишната 2D чернова (без build), пазена за справка.

## Известни ограничения на POC

- Трасирането е по прости правила; няма избягване на врати/прозорци и автоматично избиране на най-късия път.
- Устройствата се местят чрез полетата в панела, не с влачене.
- Няма врати, прозорци, етажи, спецификация на кабелни канали.
